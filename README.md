# ecommerce-profitability-analysis
Project Goal:
Conducted an end-to-end retail sales & profitability analysis for an e-commerce business ($2.3M revenue, 9.9k orders) to identify profit leakage caused by aggressive discounting and evaluate manager performance.

Key Contributions & Technical Workflow:
Data Enrichment: Cleaned raw transactional data and joined manager mappings using XLOOKUP.
Financial Modeling & Metrics: Calculated net profit margins (Profit / Sales) and aggregated category-level metrics using Pivot Tables.
Dashboard Design: Developed an executive-ready Google Sheets dashboard with high-level KPI cards, interactive charts, and business summaries.
Business Impact & Recommendations:
Discovered that discounts >20% resulted in severe profit losses, particularly in the Furniture category.
Identified margin underperformance for manager Alex (3.9% profit margin vs 15.6% for Technology).
Recommended enforcing a 20% discount cap, shifting manager incentives toward Net Margin %, saving the business thousands of dollars in lost profit.
